# 요구사항 a5
- 주어진 postID의 게시물을 좋아하는 사용자 목록 가져오기

# 조건
- PK는 `p#{{postid}}#likelist` 로 한다
- SK는 `u#{{like를 누른 user id}}` 로 한다
- 주어진 게시물을 좋아하는 좋아요가 늘어난다
  - `"PK": "p#{{postid}}#likelist", "SK": u#{{like를 누른 user id}}` create한다
    - 게시물이 존재해야한다
    - like를 누르는 유저가 존재해야한다
  

- 주어진 사용자의 게시물이 줄어든다
  - `"PK": "p#{{postid}}#likelist", "SK": u#{{like를 누른 user id}}` delete한다
