# 요구사항 a4
- 주어진 사용자가 작성한 게시물 목록을 가져오기

# 조건
- PK는 `u#{{userid}}#post` 로 한다
- SK는 `p#{{ULID_post_id}}` 로 한다
- 주어진 사용자의 게시물이 늘어난다
  - `"PK": "u#{{userid}}#post", "SK": p#{{ULID_post_id}}` create한다
    - content, imageUrl, timestamp도 같이 만들어진다
  - `"PK": "u#{{userid}}", "SK": count` 의 `post#` 을 증가시킨다

- 주어진 사용자의 게시물이 줄어든다
  - `"PK": "u#{{userid}}#post", "SK": p#{{ULID_post_id}}` delete한다
  - `"PK": "u#{{userid}}", "SK": count` 의 `post#` 을 감소시킨다
