# 요구사항 a2
- 주어진 사용자를 팔로우하는 사용자 목록을 가져오기

# 조건
- PK는 `u#{{userid}}#follower` 로 한다
- SK는 `u#{{userid}}` 로 한다
- 팔로우하는 사용자가 늘어나면
  - `"PK": "u#{{userid}}#follower", "SK": u#{{팔로워userid}}` create한다
  - `"PK": "u#{{userid}}", "SK": "count", "follower#": 늘어난만큼` update한다
  - `"PK": "u#{{userid}}#following", "SK": u#{{팔로잉하는userid}}` create한다
  - `"PK": "u#{{userid}}", "SK": "count", "following#": 늘어난만큼` update한다
  - u1는 새로운 팔로워 u2이 생겼다. 팔로워가 1 오른다
  - u2가 u1를 팔로잉 했다. u2의 팔로잉이 1 오른다
  
- 팔로우하는 사용자가 줄어들면
  - `"PK": "u#{{userid}}#follower", "SK": u#{{팔로워userid}}` delete한다
  - `"PK": "u#{{userid}}", "SK": "count", "follower#": 줄어든만큼` update한다
  - `"PK": "u#{{userid}}#following", "SK": u#{{팔로잉하는userid}}` delete한다
  - `"PK": "u#{{userid}}", "SK": "count", "following#": 줄어든만큼` update한다
  - u1는 기존 팔로워 u2이 사라졌다. 팔로워가 1 줄어든다
  - u2가 u1를 팔로잉 중단했다. u2의 팔로잉이 1 줄어든다

# 자유로운 생각
팔로우 관련 CRUD를 만들어야 한다.
팔로우 사용자 목록 가져오기를 먼저 만들고, 팔로우 사용자 목록 늘어남, 줄어듬을 만든다
